The platform

A mid-plane for planning, routing, and review

These are the pieces the mid-plane is built from.

01

Mid-plane orchestration

A LangGraph orchestration layer with dynamic model routing, so work can be sent to the model or agent that fits the task rather than locked to a single path.

02

Episode data flywheel

Every run can be stored as an episode, given a quality score, and exported for training — a closed loop from production experience back into the models and agents that do the work.

03

Composable multi-agent systems

The Dev Guild is a composable set of agents that can be combined for software and platform work, instead of a single monolithic assistant.

04

Schemas and connectors, via MCP

Platform schemas and connectors are described as metadata. Agents select and combine them through Model Context Protocol (MCP) servers, so a capability can be published once and used across the mid-plane.

05

Trading controls

Trading starts paper-only. Order-placing capability stays behind hard external controls, and is not exposed for live money until those controls are in place.

06

Observability

Runs, routing choices, and outcomes are visible as traces and episodes, so the platform can be inspected, evaluated, and improved.

How it fits together

Apps are product surfaces on the mid-plane

Product surfaces

Applications Operator tools New surfaces
Mid-plane Orchestration · episodes · schemas · controls · observability

Applications present work to people. The mid-plane plans and routes that work, records each episode, applies controls, and offers a consistent interface every app can use. New surfaces can be added without rebuilding the orchestration, training loop, or safety controls underneath.

Vision

A platform that improves from its own history

We are building toward a platform that gets better from what it has already done: agents that can see the schemas and connectors available to them, choose among them with care, and leave a trace of what they tried. The aim is a mid-plane other products can stand on — inspectable, trainable, and conservative where the stakes are high.
